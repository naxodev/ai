# Dynamic audio visualization — retired

Nacho canceled the dynamic sound graph on 2026-10-17 because its setup and permission requirements were too complex. It is no longer planned for release.

The capture protocol, native helper, diagnostic tools, and experimental sidebar are removed. Normal music playback, metadata, artwork, and the existing generated sidebar animation remain supported. They do not capture system audio.

The experiment's implementation and evidence remain in version-control history before the removal commit. Do not resume capture probes, permission setup, or release work unless Nacho explicitly revives the feature.
