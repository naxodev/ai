# Support

Use [GitHub Discussions](https://github.com/naxodev/ai/discussions) for installation, configuration, and usage questions.

Use [GitHub Issues](https://github.com/naxodev/ai/issues) for reproducible defects and focused feature requests. Include the affected package, package version, operating system, relevant host and runtime versions, reproduction steps, and redacted logs.

The music packages support macOS only. The OpenCode packages track the exact beta OpenCode version documented in their package README. Pi packages support the peer range declared in their package manifest.

Security reports must follow the private process in [SECURITY.md](SECURITY.md).
