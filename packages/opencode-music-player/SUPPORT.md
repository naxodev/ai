# Support

Use [GitHub Discussions](https://github.com/naxodev/ai/discussions) for installation and usage questions.

Use [GitHub Issues](https://github.com/naxodev/ai/issues) for reproducible defects and focused feature requests. Include your macOS version, `opencode2 --version`, package version, media backend, and relevant redacted logs.

Security reports must follow the workspace [security policy](../../SECURITY.md).
